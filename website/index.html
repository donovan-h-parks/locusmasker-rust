LocusMasker

Finds and masks the sequences in a multi-locus alignment that do not belong: too divergent from their closest relatives at a locus, or too similar to one of them. The whole analysis runs here in your browser; nothing is uploaded.

the alignment as a matrix of taxa (rows) by loci (columns), painted as each locus is tested: greys pass, reds masked as too divergent, blues as too similar
what runs here, and the limits

The page loads a Python runtime (Pyodide) and numpy, about 20 MB on the first visit and cached afterwards, and runs the tool's own script unchanged, single-threaded, on a copy of your files kept in the browser's memory. The result is the same as a server run: the same masks, the same tables, the same report. Datasets up to about a hundred taxa and a few million sites take a minute or two; beyond the memory a browser tab can hold, the page tells you so and gives the command line to run instead, with the memory and time it needs.

Nothing leaves your computer. The report you download opens from a double-click, with no server.
